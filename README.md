# Snake Game

Простая учебная змейка на C++ с модульной архитектурой, позволяющей легко добавить другой UI.

## Требования

- C++17
- Make
- ncurses

Установить на macOS: `make install-deps`

## Структура

- `domain/` — логика игры (GameEngine, GameField)
- `render/` — отображение (ConsoleRenderer)
- `input/` — обработка ввода (InputManager)
- `objects/` — игровые объекты
- `utils/` — вспомогательные функции

## Сборка

```bash
make        # Собрать
make run    # Запустить
make clean  # Очистить
```

## Расширение

Логика игры отделена от визуализации. Чтобы добавить новый UI:

1. Создайте новый класс-рендер (например, `SDL2Renderer`)
2. Реализуйте методы `Render()` и `ShowGameOver()`
3. Замените `ConsoleRenderer` на новый рендер в `main.cpp`

Остальная логика игры останется без изменений.
